## 🛠️ Technologies

- **Frontend:** Next.js 14, React, TypeScript, Tailwind CSS, Framer Motion
- **Backend:** Symfony, PHP, Node.js, MySQL
- **Design:** Figma, Photoshop, UI/UX

## 🚀 Installation

```bash
git clone https://github.com/EEnez/portfolio.git
cd portfolio
npm install
npm run dev
```
