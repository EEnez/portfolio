## 🛠️ Stack Technique

**Frontend**
- Next.js 14 + React 18 + TypeScript
- Tailwind CSS + Framer Motion
- Optimisation performance (Lighthouse 95+)

**Backend & Tools**
- Symfony + PHP 8, Node.js + Express
- MySQL, PostgreSQL
- Git, Docker, ESLint

**Design**
- UI/UX avec Figma
- Design systems et prototypage
- Adobe Creative Suite

## 🚀 Quick Start

```bash
# Installation
git clone https://github.com/EEnez/portfolio.git
cd portfolio && npm install

# Développement
npm run dev
# → http://localhost:3000
```
